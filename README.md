# Akshay Engolikar Portfolio (Modern Framework Stack)

This portfolio now runs on a modern front-end stack:

- **React + TypeScript**
- **Vite**
- **Tailwind CSS**
- **Framer Motion**

The site includes:

- Hero, summary, skills, experience, education, certifications, and contact sections
- Responsive navigation with mobile menu
- Dark/light mode with persistence
- Scroll-based active section highlighting
- Animated reveal transitions
